# skills

The agent skills I use day to day.

## Install

Copy a folder from `skills/` into `~/.claude/skills/`, or use [skills](https://github.com/vercel-labs/skills):

```
npx skills add EiSiMo/skills
```

## Skills

- **init-project**: scaffolds a new repo with MIT license, .gitignore, README and an AGENTS.md with my coding rules.
