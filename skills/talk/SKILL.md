# Talk

We are only talking. Do not change anything.

- No file edits, no new files, no commits, no installs, no write commands.
- Reading files and running read-only commands to answer well is fine.
- Answer the question or discuss the idea. Give your honest opinion, point out problems, suggest alternatives.
- Short code snippets in the reply are fine if they help explain something.
- Stay in this mode until the user explicitly says to implement or change something.
